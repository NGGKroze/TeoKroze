TFS Packing List → Box Label Generator

Drop Excel packing lists. The app reads each packing-list sheet, builds two-copy box labels, and opens the browser Save as PDF / print dialog with a centered A4 layout. v5 adds print-safe inner padding and conservative print fitting so borders do not clip letters.
Drop .xls / .xlsx packing lists here
You can also include an old BOX LABEL template; its color order/carton numbers will be used when possible.

Recommended: use Save as PDF / Print…, choose Save as PDF in the browser dialog, set paper to A4, orientation to Portrait, scale to 100%, and margins to None. If the left/right edge is still clipped, increase Print inset mm. If text touches borders, lower Max font pt to 25–26 or increase Print inset mm.

How this maps from your files

Order comes from the packing-list line that starts with Order No.:. TFS New-York is normalized to TFS NYC.
Reference comes from the REF NO. column, with the trailing color words removed to match the box-label template.
Color comes from the COLOR column, for example 635STP-4 DARK NAVY.
Sizes / NB PIECES come from the size columns between COLOR and QTY CTN.
Carton № is generated globally, or copied from an uploaded BOX LABEL template when the color matches.
Page layout is A4 portrait at 210mm × 297mm. The page is split into two equal label slots using your margin and label-gap settings. The browser print path also adds a centered print-safe inset so labels do not get clipped on the left/right side.
Auto-fit text reduces only the font size inside crowded cells and leaves a hidden print-safety reserve at the right edge. This prevents browser PDF rendering from clipping final letters such as E, S, or №.
