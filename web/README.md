# Браузърен тест на Riftbound

Отвори `web/index.html` в браузър (двоен клик, без сървър). Избираш тесте, другото получава AI противникът.

- **Тестета:** Emberclaw (агресия) и Iron Covenant (защита) — по 39 карти в основното тесте + 1 Extra (общо 80 карти). Списъци: `cards/decks.json`.
- **Правила:** виж бутона „Правила" в играта. Прототипът следва YGO структурата (8000 LP, 5 карти, 1 нормално призоваване, tribute, Snares), без Spell Speed 1/2 нюанси.
- **Тест режим:** `index.html?auto=1&speed=200&deck=emberclaw` — AI играе и за двете страни.

## Файлове
| Файл | Роля |
|---|---|
| `web/engine.js` | правилата (работи в браузър и Node) |
| `web/ai.js` | бот: само публична информация + собствената му ръка |
| `web/ui.js`, `web/index.html` | интерфейс |
| `web/data.js` | генериран от `tools/build_cards.py` — не се редактира на ръка |
| `tools/simulate.js` | AI срещу AI симулации за баланс |

## Баланс
```
python3 tools/build_cards.py          # прегенерира cards/*.json и web/data.js
node tools/simulate.js 4000 20000     # 4000 мача, редуващи се страни и първи играч
```
Последен резултат (4000 мача, seed от 20000): Emberclaw 49.1% / Iron Covenant 50.9%, първият играч печели 49.6%, средно 11.7 хода, 0 грешки.
`DECK_PATCH='{"emberclaw":{"ember_spark":2}}'` и `CARD_PATCH='{"ashmane_lion":{"atk":1600}}'` позволяват бързо пробване на промени без редакция на файлове.

**Ограничение:** балансът е измерен между два еднакви евристични бота. Реални играчи (особено на Iron Covenant: позициониране, Snares) ще се различават — вземи го за отправна точка, не за доказателство. Препоръка: 20+ ръчни мача и корекция на `tools/build_cards.py`.

## Опростявания спрямо плана
- Тригерите на Units са автоматични; верига има само чрез Snares/Counter (без ръчно Quick Tactic в чужд ход).
- Няма face-down Units и няма Chain Link със Spell Speed проверки.
- Астрални Weavers са в данните, но без тесте и без поддръжка на техните ефекти (`reveal_top`, `send`) в енджина.
