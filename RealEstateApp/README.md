# Имоти Русе (Android)

Лично приложение за търсене на имоти **за продажба** в Русе и областта от imot.bg, alo.bg и OLX.

- **Търсене**: район (град Русе / около Русе без града / цялата област), вид имот, цена, квадратура, ключова дума, сайтове; сортиране по цена и €/м².
- **Любими**: ♡ на всяка обява; пазят се на телефона.
- **Профили за известия**: всеки профил е отделно търсене (напр. „Къщи до 50 000 € в Русе“, „Къщи до 70 000 € около Русе“) със собствени настройки:
  колко често да проверява (всеки час … веднъж на ден), отделно известие за всяка обява или едно общо, лимит на известията, без звук, тихи часове.
  Известие идва **само когато има нови обяви**. Разделът „Нови“ показва откритото по профили.
- **Обява**: снимки, характеристики, описание, бутони за обаждане, имейл, карта, споделяне и отваряне в сайта.

## Инсталиране
APK се сглобява автоматично от GitHub Actions при всеки push (workflow „Android APK“).
Свали `ImotiRuse.apk` от release **apk-latest** (или от артефактите на workflow-а) и го отвори на телефона.

## Структура
- `core/` – чист Kotlin: модели, филтри и парсери за сайтовете (тестват се без Android SDK).
- `app/` – Android приложението (Jetpack Compose, WorkManager).

```
./gradlew :core:test -PcoreOnly        # тестове на парсерите
./gradlew :core:liveCheck -PcoreOnly   # проверка срещу истинските сайтове
./gradlew :app:assembleRelease         # APK (изисква Android SDK)
```

Парсерите разпознават обявите по формата на линковете им (напр. `alo.bg/5749048`), а не по CSS класове, така че малки промени по сайтовете не ги чупят. Ако сайт смени адресите си, поправката е в `core/src/main/kotlin/.../sources/Sources.kt`.
